# Projeto-e-commerce-HTML5-CSS3-Bootstrap-e-JavaScript
Projeto de e-commerce (Eletro-Tech-Store) desenvolvido com HTML5, CSS3, Bootstrap e JavaScript - desenvolvimento web.


# 🛒 Relatório de Atividades e Documentação do Projeto

Registro consolidado das ações técnicas, organização de arquivos, estrutura e versionamento do projeto **Eletro-Tech-Store & Grid System**.

---

## 📌 1. Visão Geral do Projeto

Este repositório é composto por dois módulos principais em **HTML5** e **Bootstrap 5**:

* **Lojinha (`index.html`):** Interface interativa de um carrinho de compras para uma loja de eletrônicos, contendo tabela dinâmica de produtos, controle de quantidade e subtotal.
* **Grid System (`grid.html`):** Demonstração prática do sistema de grids e cartões (*Cards*) responsivos do Bootstrap.
